Audio

Los 64 audios provisionales se generaron con la voz sintética Microsoft Helena (es-ES) a partir de guiones propios. Se sustituirán por locución humana. La transcripción de cada audio es nuestra.

Datos y cartografía

  • Clima: Open-Meteo, consultado desde el navegador, con AEMET como referencia oficial.
  • Coordenadas y aparcamientos: OpenStreetMap, datos de sus colaboradores (ODbL).
  • Mapas: Leaflet 1.9.4 (licencia BSD de 2 cláusulas), alojado en el propio sitio, con teselas de OpenStreetMap. La atribución aparece dentro de cada mapa.
  • Fotografías: Wikimedia Commons.
  • Tipografías: Atkinson Hyperlegible (Braille Institute) para el texto y la interfaz, y Literata (TypeTogether) para titulares y marca. Ambas se autoalojan con la SIL Open Font License; las licencias completas están en assets/fuente/.

Marca

El logotipo, el emblema y el favicon son propios. El nombre del logotipo se ha convertido a trazos a partir de Literata, así que se reproduce igual aunque la fuente no esté instalada. Archivos: logo.svg, logo-claro.svg, logo-emblema.svg, logo-emblema-claro.svg y favicon.svg.

Privacidad

El sitio no usa cookies, analítica ni píxeles de seguimiento. No hay cuentas ni formularios que envíen datos a un servidor propio.

El navegador hace dos peticiones a terceros: Open-Meteo, para el tiempo, y las teselas de OpenStreetMap, para los mapas. Como en cualquier petición web, esos servicios reciben la IP y el agente del navegador y se rigen por sus propias políticas. No se les envía nada más. El audio, las fuentes y las imágenes se sirven desde este mismo sitio.
