# Audios provisionales

64 audios, 8 por ciudad, generados con la voz sintética **Microsoft Helena
(es-ES)** el 2/11/2026. Sirven para probar la app y el reproductor.
**No son la versión final**: la producción definitiva usa voz humana y los
guiones del apartado 5 de cada ficha.

Formato publicado: **MP3 mono, 22.050 Hz, 64 kbps**. Los WAV mono, 22.050 Hz,
16 bits, se conservan como fuente y no se publican. Textos en
`audio/scripts.json`; el generador reescribe las rutas publicadas en
`sitio/audio/scripts.json`.

## Aviso de duración

Los guiones tienen **65–100 palabras** (mediana 69) y están escritos para
**40–60 segundos con ritmo pausado**. El TTS los lee en 31–38 segundos: habla
más rápido que una locución humana pausada. Al grabar con voz humana, no
aceleres para igualar esta tabla; respeta el ritmo del guion.

## Cómo sustituirlos por voz humana

1. Grabar cada guion con ritmo pausado y sin música de fondo.
2. Guardar el WAV de origen en `audio/<ciudad>/<número>.wav` y convertirlo con
   `herramientas/convertir_audio.py` (MP3 mono, 22.050 Hz, 64 kbps, mismo nombre).
3. Mantener la transcripción sincronizada con el audio.
4. Revisar que el texto no prometa accesibilidad no verificada.
